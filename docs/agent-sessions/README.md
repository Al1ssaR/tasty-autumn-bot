# Реальные экспорты сессий Codex

Исходное тестовое задание просит приложить 2–3 ключевых лога AI-agent. В текущей среде нет поддерживаемой команды или функции интерфейса для экспорта сессии Codex в переносимый файл. Внутренние служебные файлы приложения не добавляются в репозиторий как подмена пользовательского session export.

Fake transcripts и реконструкции по development prompts намеренно не создавались.

Перед передачей репозитория пользователь должен экспортировать из интерфейса Codex 2–3 настоящие сессии, если такая функция доступна в используемой версии приложения, и положить полученные файлы в этот каталог без секретов и лишних персональных данных. Предпочтительные реальные этапы:

1. построение MVP: архитектура, БД, Telegram, LLM и baseline;
2. controlled LLM iteration: анализ `bot-v1`, создание `bot-v2`, comparative evaluation;
3. завершение продукта: operator panel, statistics и final audit.

Если фактические границы сессий отличаются, следует использовать реальные экспорты без искусственного объединения или деления истории.
